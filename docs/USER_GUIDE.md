# SpainDaily 使用说明

## 第一次使用

1. 用手机打开 SpainDaily 的 HTTPS 地址。
2. 点“选择加密行程包”，选择收到的 `.spaintrip` 文件。
3. 输入资料包密码。密码只在当前设备内用于解密，不会上传，也无法由服务器找回。
4. 看到旅客选择页后，点自己的名字。每次彻底重新打开都会再次要求确认；上次选择只会高亮。
5. 在“我的”中点“重新检查离线资料”，确认所有附件完整。

## 添加到主屏幕

- iPhone / iPad：Safari 分享菜单 →“添加到主屏幕”。
- Android：Chrome 菜单 →“安装应用”或“添加到主屏幕”。

安装入口名称会随系统版本略有不同。先在线完整打开一次并完成导入，再测试飞行模式下重开。

## 每天使用

- “今日”自动按“我的”中选择的参考时区判断日期。
- 横向日期条可以预览未来；日历按钮显示从行前到最后返程的完整日期网格，预览页会显示“回到今天”。应用从后台恢复或跨过午夜时会重新判断日期；主动预览未来时不会被强制跳走。
- 点行程卡查看当地时间、地点、本人预订、原票和来源。地点区可打开地点、从当前位置导航、查看上一站路线、复制地址、拨打已核验电话，并明确标出未经核验的天气与附近搜索入口。
- 票据全屏查看时保留原图；不要把应用截图当作供应商保证认可的动态票证。
- 任务默认只露出少量重点，可展开其余项目；“提前准备”和“当天处理”会单独标记。任务、忽略状态、事件完成/跳过和笔记按旅客分别保存。
- 建议事件可保存个人时间调整；原文和官网时间不会被个人修改覆盖。
- “资料攻略”可按地点、交通、正文或来源搜索；“原文页”保留复杂表格和页面上下文，只存在加密资料包内。

## 离线边界

离线时可查看已经导入的日程、攻略、票据和图片，也可以勾任务、写笔记。在线地图、实时交通、天气、航班动态和供应商网站不会变成离线实时服务；地址仍会保留。

## 备份与换手机

1. 在“我的 → 加密备份”设置至少 8 位新密码。
2. 下载 `.spaintrip` 备份，并把文件和密码分开保存。
3. 换手机后打开公开网站，导入该备份。

“我的”会显示最近一次成功备份的本机时间；它只是一条本地记录，不代表文件已经同步到云端。

不同设备不会自动同步。浏览器清理网站数据可能删除本机资料，因此重要修改应定期备份。

## 删除本机资料

“我的 → 删除这台设备上的行程”会删除 IndexedDB 内的行程、附件、任务和笔记；不会删除你的原始 Word/PDF 或其他设备上的备份。删除不可撤销。
